# NaturaPin — website

The support and privacy pages for NaturaPin, a notebook for the forest: mark where you found mushrooms, berries and fish — and the rest stops along the way — so you can find your way back next year.

* [Support](https://haj728.github.io/naturapin-site/support.html)
* [Privacy Policy](https://haj728.github.io/naturapin-site/privacy.html)

This repository contains only these pages. The app's source code is not here.
Bug reports and questions about the app are welcome in [Issues](https://github.com/HAJ728/naturapin-site/issues).
